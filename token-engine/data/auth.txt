Authentication Guide

Authentication Flow

The login service validates user credentials using email and password. After successful verification, a JWT token is generated and attached to the response. Middleware checks token validity on every protected route. Session expiration is handled through token expiry timestamps.

Passwords are hashed using bcrypt before being stored in the database. Password hashing prevents passwords from being stored in plain text.
