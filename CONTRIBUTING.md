# Contributing to File Optimizer

Thank you for your interest in contributing to File Optimizer.

Contributions of all sizes are welcome, including:

* Bug fixes
* Performance improvements
* New file format support
* Better chunking strategies
* Improved ranking algorithms
* Agent framework integrations
* Documentation improvements

---

## Getting Started

### 1. Fork the repository

Create your own fork and clone it locally.

```bash
git clone <your-fork-url>
```

---

### 2. Create a branch

```bash
git checkout -b feature/your-feature-name
```

---

### 3. Make changes

Implement your changes and ensure existing functionality remains intact.

---

### 4. Commit

```bash
git commit -m "feat: add your feature"
```

---

### 5. Push

```bash
git push origin feature/your-feature-name
```

---

### 6. Open a Pull Request

Describe:

* What was changed
* Why it was changed
* Any benchmarks or tests performed

---

---

# Coding Guidelines

* Keep components modular.
* Preserve readability.
* Avoid unnecessary dependencies.
* Prefer small focused changes.
* Add tests when appropriate.

---

# Reporting Issues

Please include:

* File type
* Input data
* Expected behavior
* Actual behavior
* Error logs (if any)

---

# Philosophy

File Optimizer prioritizes:

1. Relevance over aggressive compression.
2. Simplicity over unnecessary complexity.
3. Modularity over tightly coupled designs.

Thank you for helping improve File Optimizer.
